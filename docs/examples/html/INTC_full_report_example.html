估值解讀

股權融資會稀釋 per-share economics，但若融資現金仍在 balance sheet，市值增加與 net debt 下降會互相抵銷一部分，因此不能把「稀釋」直接翻譯成 EV 同幅上升。完整報告應同時呈現 per-share dilution 與 EV bridge。
