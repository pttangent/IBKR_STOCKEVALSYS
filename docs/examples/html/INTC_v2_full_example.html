BRANCHING MIND MAP / 分叉思維圖
OPEN / 開盤先判斷 gap 與 prior close / R1 / S1 的相對位置
SIZE // WAIT
GAP UP / 高開open > prior close；若 >R1 則進一步觀察 acceptance
ACCEPT / 衝高延續
IF // ORH above R1 → VWAP hold → retest R1 holds
THEN // higher-low / R2 test
INVALID // lose VWAP + R1 reclaim fails
SIZE: QUARTER → HALF only after confirmation
FADE / 衝高回落
IF // gap loses R1/VWAP/prior close
THEN // reassess near S1
INVALID // strong reclaim of failed level
SIZE: NONE / WAIT
NEAR FLAT / 平開open around prior close；避免用第一根 bar 強行判方向
BREAK UP
IF // ORH break + VWAP above + R1 acceptance
THEN // follow-through to R2
SIZE: QUARTER
RANGE / 壓縮
IF // ORL < price < ORH
THEN // wait for hold outside range
SIZE: NONE
GAP DOWN / 低開open below prior close；先分 acceptance 還是 reversal
ACCEPT / 弱勢延續
IF // S1 failed → VWAP rejected
THEN // test S2
SIZE: NONE for long setup
REVERSAL / 低開反轉
IF // reclaim S1 → VWAP → ORH retest holds
THEN // reversal setup only, not trend proof
SIZE: QUARTER
WHAT
把開盤結果先分高開/平開/低開，再看 acceptance / fade / reversal。
每個葉節點都有 IF / THEN / INVALID / SIZE。
READ
盤前不是預測開盤方向，而是先定義看到不同價格反應時怎麼處理。
真正提高 sizing tier 的是確認，而不是 gap 本身。
WHY
同一個 gap-up 可以是 continuation，也可以是 liquidity fade；兩者風險動作相反。
Tree 強迫研究層保留替代路徑。
LIMIT
若沒有 same-session ORH/ORL/VWAP，tree 只能是 pre-open plan。
不能把 prior-day levels 寫成「今日已確認」。
